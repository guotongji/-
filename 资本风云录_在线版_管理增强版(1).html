接入与账号管理指南

1. 建项目
打开 supabase.com 免费注册，New Project，记下项目名。

2. 取密钥
Project Settings → API，复制 Project URL 与 anon public key。

3. 填配置
用记事本打开本 HTML，把顶部两处 PASTE_SUPABASE_URL / PASTE_SUPABASE_ANON_KEY 替换为上面两项，保存。

4. 建表（SQL Editor 运行）

-- 用户资料表
create table profiles(id uuid primary key references auth.users on delete cascade, username text, nickname text, created_at timestamptz default now());
alter table profiles enable row level security;
create policy "own read" on profiles for select using (auth.uid()=id);
create policy "own write" on profiles for insert with check (auth.uid()=id);
create policy "own update" on profiles for update using (auth.uid()=id);
-- 允许任何人统计注册总数（管理用）；如需限制可改为 service_role
create policy "count all" on profiles for select using (true) with check (false);
-- 云端存档表
create table saves(user_id uuid primary key references auth.users on delete cascade, data text, updated_at timestamptz);
alter table saves enable row level security;
create policy "own save" on saves for all using (auth.uid()=user_id) with check (auth.uid()=user_id);
-- 允许管理端读取存档更新时间，用于「近7日活跃」统计（仅放开只读）
create policy "stats read" on saves for select using (true) with check (false);
-- 关闭邮箱确认（让注册后即可登录；生产建议保留）
-- 控制台 Authentication → Providers → Email → 关闭 Confirm email

5. 查看注册数与活跃
① 游戏登录页点「管理 · 数据统计」，弹出面板实时显示：累计注册 / 今日新增 / 近7日活跃 + 近14天注册趋势图；（活跃数依赖第4步的 saves「stats read」策略，未加则活跃显示为 0）
② 或登录 Supabase 控制台 → Authentication → Users 查看完整列表、注册时间、禁用 / 删除 / 重置账号。

未填密钥时自动进入本地模式，游戏仍可双击离线玩，进度存本机浏览器。

6. 部署到 Cloudflare Pages（生成可点开的网址）
完成第1~5步后，把游戏做成一个玩家点链接就能注册游玩的网址：
① 把本文件重命名为 index.html（纯静态托管必须以 index.html 为入口）；
② 打开 dash.cloudflare.com 免费注册 → 左侧 Workers & Pages → Create → 选 Pages → Upload assets；
③ 项目名称随意（如 capital-game），直接把只装着 index.html 的文件夹拖进去 → Deploy Site；
④ 几秒后得到 https://你的项目名.pages.dev，把网址发给任何人，对方打开即可注册游玩，你在「管理 · 数据统计」即可看到注册数增长。
提示：Cloudflare Pages 免费额度足够个人小游戏；国内访问速度通常优于 Netlify；无需自己买服务器。
